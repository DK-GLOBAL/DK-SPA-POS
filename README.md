# DK SPA POS – Barber, Salon & Spa Manager

A lightweight Point of Sale (POS) and management system built for barbershops, salons, and spas. Developed by **DK Global Tech**.

## Project Structure
- `index.html` – Application shell and mount points
- `style.css` – Stylesheet with theme variables, dark mode, and responsive layout
- `app.js` – Application state, bookings, POS sales, M-Pesa Daraja helper, WhatsApp links, and views

## Usage
1. Open `index.html` in a web browser or deploy the folder to GitHub Pages / Vercel.
2. Add `#demo` at the end of the URL to explore sample data locally.
